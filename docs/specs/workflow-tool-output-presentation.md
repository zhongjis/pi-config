# Workflow Tool and Notification Presentation (Historical)

Status: retired

This record describes the removed `SubagentWorkflow` script runtime. `SubagentWorkflow`, `wf_` run IDs, `$subagentWorkflowOutcome`, and the old “Workflow” UI are not current contracts. Do not use this document to specify graph or Subagent presentation.

[ADR 0002](../adr/0002-remove-subagentworkflow-script-runtime.md) records the script-runtime removal; [ADR 0003](../adr/0003-retire-workflow-terminology.md) records the graph terminology migration. For current presentation, use the [cross-Extension tool-output rendering guide](../guides/tool-output-tui-rendering.md), [Subagent tool-output presentation spec](subagent-tool-output-presentation.md), and [Herdr agent-graph presentation spec](herdr-agent-graph-presentation.md).
